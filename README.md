# 闲鱼发布助手

面向 Codex 的个人技能：复用电脑浏览器中的闲鱼登录状态，完成商品查价、文案、水印封面、发布及原商品编辑。

## 使用

把本仓库内容放到 `~/.codex/skills/xianyu-publish/`，然后在 Codex 中调用：

> 用 $xianyu-publish 帮我查同款行情，制作水印封面，并发布这个商品。

也可以让 Codex 从本仓库安装该技能。技能元数据允许正常自动发现。

## 环境

- 已安装 OpenCLI、浏览器桥接扩展，以及 `opencli-usage` 和 `opencli-browser` 技能。
- 用户自己的闲鱼浏览器会话已登录；支持该会话的浏览器即可，不限定 Chrome 品牌。
- 图片生成和编辑使用可用的 `imagegen` 技能及内置工具。
- 自定义控件或确认弹窗需要时使用 `cua_repl` 原生应用操作。

## 个性化

默认水印为 **闲鱼@scum_d**。用于其他店铺时，请修改 `SKILL.md` 与内容参考中的水印，并核对实际登录账号。

本仓库不保存 Cookie、券码或登录凭证，也不包含任何实际可核销的代金券。价格、费率、库存和商品规则应在每次任务中重新确认。

## 文件

- `SKILL.md`：技能入口、范围和结果核验要求。
- `references/content-and-pricing.md`：同条件券价比较、收益估算和封面文案。
- `references/browser-workflow.md`：登录状态、发布、原商品编辑和故障处理。
- `agents/openai.yaml`：技能显示名称与默认调用提示。

已通过技能格式检查及只读情景演练；浏览器流程来自实际操作验证，网站更新仍可能需要调整。
